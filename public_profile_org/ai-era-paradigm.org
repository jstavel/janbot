# The AI-era development paradigm — determinism, information density, and the gardener role

* The claim

The AI era breaks the **local maximum of "we use what the team already knows"**.
The argument *"we write Python, so we'll use Python"* loses its relevance: a model
handles a wide spectrum of languages (specialised and old ones included), and **the
constraint is now our own comfort zone, not the tool**. Slowing the AI down to the
languages we happen to know is a self-inflicted limit — the model should not be
braked by the team's knowledge.

* Determinism and information density gain value

Statically-typed and functional languages — **TypeScript, Rust, Clojure** — become
*more* valuable, not less, because their strict rules bring **determinism** into the
broad, probabilistic behaviour of a model:

- fewer **hallucinations** and less noise,
- less **boilerplate**: higher *information density* means more of the solution is
  visible in fewer lines, and better orientation for both the human and the model,
- the trade-off: higher density demands **more conceptual understanding** from the
  expert — and there will still be moments that need a deep specialist.

* The role shift: from writer to gardener

The engineer moves from writing base code to **cultivating and steering** the
model's output — an *observer and shaper* ("sadař", the gardener) who gives the
system room and only **corrects the direction**, instead of micromanaging syntax.
(Cross-reference: the same gardener model as the *relational* principle in
`20261016-respectful-partnership`.)

* The junior entry point changes

The historical sequence — assembler, then C/PHP, then Python/Java — **stops being a
dogma**. A new generation can start **directly at higher abstraction** (Lisp,
Clojure) and learn **in tandem with the AI**, using it to accelerate their own
growth. If the ladder's bottom rung no longer exists (who starts with assembler
today?), why force the next generation to climb it? New juniors stand in an empty
field — and can be taught from where the AI already is.

* Honest limit

The shift is *felt* more than *fully articulated*: the direction is clear
(determinism, density, cultivation, higher entry levels), the exact set of changes
is not yet pinned down — an open question, not a closed conclusion.
