# Nagios + SNMPv3 monitoring with ASN.1 contracts

During OSVČ work as a Linux administrator (approximately 2003–2005), this
person configured Nagios for site monitoring. Monitored stations ran either
shell scripts or Perl modules for SNMPv3 (Simple Network Management Protocol
v3 — the standard for network device discovery and monitoring).

**Infrastructure stack from the same period:**
- qmail-ldap — mail server with LDAP integration
- Samba 3.0 as Primary Domain Controller
- Amavis — antispam gateway
- stunnel + CA — secured Sybase tunnels between companies (Ganymed project)
- ASN.1 → C code generation — contract-driven data exchange between
  central server and clients, years before Google Protocol Buffers (2008)

**The ASN.1 project** is particularly notable: ASN.1 was used as an Interface
Definition Language (IDL) to define data contracts between systems, with
C code auto-generated from the specification — the same principle now
applied as Spec-First development, two decades later.

* What this demonstrates

- **Infrastructure & networking knowledge** — SNMP, LDAP, DNS, DHCP,
  routing, PKI, TLS tunnelling, mail protocols
- **Monitoring expertise** — Nagios/SNMP in production, not just theory
- **First instance of the "Code as Data" DNA thread** — ASN.1 → C code
  generation in 2003 is the earliest known instance of this principle
  in the corpus
- **Not QA experience** — infrastructure experience that complements the
  later enterprise QE career: understands what happens below the application
- **Continuity** — from Linux admin with Nagios/SNMP, through enterprise
  QE at Red Hat, to today
