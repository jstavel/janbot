# Linux From Scratch — system cloning with netcat and dd on a single floppy

When working as an IT administrator at a high school, this person built a
custom Linux From Scratch distribution fitting on a single 1.44MB floppy
disk, containing only two programs: `nc` (netcat) and `dd`.

**The workflow:**
- Boot the floppy on the source machine → `dd if=/dev/sda | nc -p PORT IP`
- Boot the same floppy on the target machine → `nc --listen --wait | dd of=/dev/sda`

This allowed cloning Windows 95 workstations across the network without
reinstalling — faster, simpler, and repeatable.

* What it demonstrates

- Deep Linux fundamentals, not just surface-level administration
- Creative problem-solving with minimal resources (two CLI tools, one floppy)
- Self-reliant engineering mindset — building what you need from scratch
- Understanding of disk I/O, pipes, network streaming, and bootable media

This is a recurring pattern: the same curiosity that led to overloading
C++ operator new, building a custom memory allocator, or today using
Spec-First with AI — different tools, same mindset.
