# C++ operator new — discovering memory allocator internals

During university, this person discovered that C++ `operator new` can be
overloaded. This led to studying and building a custom memory buffer
allocator with **guard bytes (canary bytes)** at allocation boundaries.

**The mechanism:**
- Pre-allocated pool with items stored between guard byte regions
- On deallocation, guard bytes were checked for corruption
- Detected buffer overflows and null pointer errors at free time

```
[GUARD_BYTES][  ALLOCATED ITEM  ][GUARD_BYTES]
              ↑                                    ↑
         on delete, pattern is checked → detects overwrite
```

This is the same technique used by Valgrind, Electric Fence, and
similar memory debugging tools — a custom bounds-checking allocator,
built from first principles long before those tools were understood.
