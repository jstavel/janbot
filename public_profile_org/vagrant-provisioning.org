# Vagrant, libvirt & Packer — IaC for test environments at Red Hat

At Red Hat, this person used a full provisioning stack for test environments:

- **Vagrant + libvirt** — orchestration of virtual machines
- **Packer** — creating reproducible VM images for KVM/libvirt
- **Multi-node clusters** — provisioning multiple machines on a single hypervisor

**Principles applied:**
- **Infrastructure as Code** — environments defined in code, not manual setup
- **Immutable infrastructure** — images rebuilt from scratch, never patched in place
- **Reproducibility** — every test runs in an identical environment

**Continuity with later projects:**
- Krakatoa (Clojure/matching engine) used KVM + Podman with Packer/Terraform
  for .qcow2 images — same principles, modern tooling
- Podman in CI/CD (rootless, daemonless) continued the pattern

* What this demonstrates

- **Infrastructure as Code discipline** — test environments are code, not snowflakes
- **Provisioning experience** — relevant for Platform Engineer / DevOps roles
- **Continuity** — same principles across Vagrant (2010s) → Packer/Terraform (2020s)
  → Podman (present)
